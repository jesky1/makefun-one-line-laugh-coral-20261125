One funny line, written by a small deterministic Node program for make.fun's "One Line, One Laugh" bounty ($2 in USDC). The joke pairs two things that die at 1% — a bank account and a phone battery — and gives them the same guilty coping strategy.

## Run it

```sh
node main.ts
```

It validates the line (1–200 characters, one line, no trailing whitespace, no control or invisible characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Tests

```sh
node --test test.mjs
```
